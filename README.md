# TV Плеер

Локальный медиаплеер для Smart TV с управлением пультом («10-foot UI»).
Чистый HTML/CSS/JS без сборки, зависимостей и внешних CDN — работает без интернета.

## Запуск

### Вариант 1. Сервер в домашней сети (рекомендуется)

Нужен Python 3.7+ на компьютере с видео.

```bash
python3 server/tv_server.py "/путь/к/папке/с/видео"            # порт 8080
python3 server/tv_server.py "D:\Видео" --port 9000               # Windows
```

Сервер напечатает адрес вида `http://192.168.1.10:8080/` — откройте его в браузере телевизора.
Библиотека подключится автоматически. Сервер отдаёт файлы с поддержкой HTTP Range
(перемотка работает и на многогигабайтных файлах) и CORS.

### Вариант 2. Без сервера (USB / file://)

Скопируйте папку проекта на флешку и откройте `index.html` в браузере ТВ, затем
«Открыть папку» или «Выбрать файлы». Видео и субтитры читаются напрямую с диска.
Можно также открыть `index.html` с флешки и ввести адрес сервера вручную.

## Управление

| Клавиша | Библиотека | Плеер |
|---|---|---|
| ← ↑ → ↓ | перемещение фокуса | панель скрыта: ←/→ — перемотка ±10 с; иначе — фокус |
| OK / Enter | открыть видео | панель скрыта: пауза; иначе — нажать кнопку |
| Назад / Esc / Backspace | очистить поиск → к поиску → выбор источника | вернуться в библиотеку |
| ⏯ ⏪ ⏩ ⏹ (медиа-клавиши) | — | пауза, ±10 с, выход |

На полосе прогресса ←/→ перематывают на 10 с. Действий «только при наведении мыши» нет,
все интерактивные элементы не меньше 48 px.

## Возможности

- **Библиотека:** сетка карточек, превью из первого кадра (если он чёрный — кадр
  на 10% длительности), длительность, метка «CC», прогресс и «Просмотрено».
  Поиск без учёта регистра и `ё/е`, по названию и папке.
- **Плеер:** пауза, ±10 с, громкость, полноэкранный режим, «С начала».
- **Субтитры:** `.srt`/`.vtt` с тем же именем рядом с видео (`Фильм.srt`, `Фильм.ru.srt`,
  `Фильм.en.vtt`) или в подпапке `Subs/`. Кодировка UTF-8 или Windows-1251 определяется
  автоматически, по умолчанию включаются русские.
- **Resume:** позиция сохраняется каждые 5 с, при паузе, перемотке и выходе
  (localStorage) и восстанавливается при следующем открытии, в т.ч. после перезапуска.

## Ограничения

- Форматы зависят от браузера ТВ: надёжно — MP4 (H.264/AAC) и WebM. MKV/AVI/HEVC
  могут не воспроизводиться — плеер покажет сообщение.
- Позиции и превью хранятся в браузере отдельно для каждого источника-адреса
  (сервер и `file://` — разные хранилища).
- В режиме `file://` после перезапуска папку нужно выбрать снова (ограничение
  безопасности браузера); позиции просмотра при этом сохраняются.
- Целевые браузеры — Chromium 53+ (Tizen 4+, webOS 4+) и любые современные.

## Структура

```
index.html          разметка трёх экранов
css/app.css         тёмная тема, фокус-кольцо
js/nav.js           пространственная навигация, коды клавиш пультов
js/library.js       сетка, поиск, превью (js/thumbs.js)
js/player.js        плеер, OSD, субтитры, resume
js/sources.js       источники: локальные файлы и сервер
js/subtitles.js     поиск субтитров, SRT → WebVTT
js/storage.js       localStorage / IndexedDB
server/tv_server.py сервер на стандартной библиотеке Python
```
